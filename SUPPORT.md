# Support

## How to file issues

The upstream [Azure Basic Workshop issue tracker](https://github.com/Azure-Samples/AzureBasicWorkshop/issues) tracks bugs and feature requests. Search existing issues before opening a new issue. The current fork does not have Issues enabled.

Include the lab and step, the browser or VM image you used, and the expected and actual results. Remove credentials, subscription and tenant IDs, personal resource identifiers, and private information from logs and screenshots.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
